This is a homepage for our projects that currently hosts **DK Converter**: an image converter that turns images into large ASCII-style art, then compresses the result with run-length encoding (RLE). Future plans: host games we coded and showcase other projects.

Features
- Converts images into large ASCII-style art
- RLE compression for output
- Adjustable output dimensions
- Pixelated upscale
- GIF support
- Faster redraws via optimized image loading
- Custom k-means color reduction with user-controlled palette size

Website
- Visit: digitsandkineto.com

Usage
- Upload or drag-and-drop an image or GIF.
- Set desired output width/height and choose palette size for k-means color reduction.

Why DK Converter is special
- Combines ASCII-style rendering with efficient RLE compression
- tunable k-means palette for charecter compression

- Crazy fast loading and redraw
