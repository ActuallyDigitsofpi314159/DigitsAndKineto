JPEG columns are measured by the DK Converter in the browser at the listed image quality; opaque stills only support JPEG. The WebP columns use FFmpeg lossy WebP at q:v 20 or 50, then DK's palette or lossless encoder, matching the alternate WebP pipeline used for transparent/animated media. All entries show payload characters only; generated renderer utilities are excluded. Tac's column uses FFmpeg qscale 2 JPEG encoded as Base85, with a separate 10,652-character decoder. These quality settings do not guarantee visual parity between encoders. Reproduce the full 8-fixture, 7-encoder Node matrix with node dkconverterstats/benchmark.cjs --all-fixtures; it uses one size sample per pair (timings are illustrative, not medians). The two JPEG modes were also run in the browser for every opaque fixture.

Exact Tac tutorial sample, 600×600

The tutorial's supplied JPEG is 9,316 bytes (11,645 Base85 characters); Tac's decoder is 10,652 characters. DK's generated draw-function code already includes the image data, so combined size is generated code plus utility.
